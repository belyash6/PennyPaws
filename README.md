# PennyPaws
Aplikacja mobilna Wallet tracker

### Cel: 
Implementacja aplikacji, która umożli na szybkie zapisywanie codziennych przychodów i wydatków. Pozwoli przeglądać je w podziale na kategorie i miesiące oraz sprawdzać, na co najwięcej pieniędzy wydaje użytkownik.Aplikacja działa bez rejestracji i logowania, a dane są przechowywane lokalnie na urządzeniu użytkownika. 
### Technologie:
środowisko: VS Code
React Native + Expo
TypeScript
expo-sqlite lub AsyncStorage (lokalny zapis danych)
GitHub
### Grupa docelowa: 
Studenci oraz młodzi ludzie, którzy chcą kontrolować lub nauczyć się kontrolować swój budżet.
### Wymagania funkcjonalne:
dodawanie, usuwanie, edycja transakcji (formularz do wpisywania kwoty, kategorii, data, typ: wydatek/przychód, opis)
lista transakcji (możliwość sortowania po dacie)
wyszukiwanie i filtrowanie (kategoria, miesiąc, typ) 
podsumowanie miesiąca: suma wydatków, przychodów i saldo (prosty widok typu wykres kołowy)
ustawienie miesięcznego limitu budżetu z ostrzeżeniem po jego przekroczeniu 
trwały zapis danych 
### Wymagania niefunkcjonalne:
prosty, minimalistyczny interfejs
tryb offline
responsywność
prywatność: dane nie opuszczają urządzenia użytkownika 
### Możliwe rozszerzenia:
tryb ciemny
obsługa kilku walut
